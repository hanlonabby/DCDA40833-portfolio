# Adding PDF Files to Your Portfolio

## Quick Setup Guide

### IMPORTANT: Add Your Resume
1. **Save your resume PDF** in this `pdfs/` folder
2. **Name it:** `Abby-Hanlon-Resume.pdf` (exactly this name - required for the Work Experience page)
3. The resume will automatically display on the Work Experience page

### IMPORTANT: Add Your Three Project Presentations

Your carousel is set up for three specific projects. Add these PDFs to this folder:

1. **7-Eleven Presentation**
   - Filename: `7eleven-presentation.pdf`
   - Used on: project-7eleven.html
   
2. **Social Media Portfolio**
   - Filename: `social-media-portfolio.pdf`
   - Used on: project-social-media.html
   
3. **Tecovas Presentation**
   - Filename: `tecovas-presentation.pdf`
   - Used on: project-tecovas.html

### Create Thumbnail Images

For each project, create a thumbnail image to display in the carousel:

1. **Take a screenshot** of the first slide or a representative image from each presentation
2. **Save as JPG** in the `images/` folder with these exact names:
   - `7eleven-thumbnail.jpg`
   - `social-media-thumbnail.jpg`
   - `tecovas-thumbnail.jpg`
3. Recommended size: 1200x800px for best quality

### Customize Your Project Pages

Each project page is ready for you to personalize:

1. Open the HTML file (project-7eleven.html, project-social-media.html, or project-tecovas.html)
2. Update:
   - Project date
   - Project overview description
   - Key highlights
   - Skills demonstrated
3. Make sure the content tells the story of each project
