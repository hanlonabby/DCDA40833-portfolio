Semester Reflection

Throughout this semester, I have worked with various aspects of coding languages to produce different types of projects for a personalized portfolio that highlights projects implementing CSS, HTML, and JavaScript, as well as previous projects that strengthen my overall portfolio and professional experience. Throughout this project, I wanted the message of functionality with user experience to be at the forefront. This semester, I’ve focused primarily on strengthening my skills in visual appeal and user interaction. Since my generation’s attention spans are limited, I feel it’s important to find innovative ways to present long-form text and detailed information.

Digital Culture

In this portfolio, I explain and visualize many concepts that are currently relevant to digital culture. As mentioned in my overview, my main goal towards the end of this project was to make my website as interactive as possible, using drop-downs and click-through slideshows, to increase engagement with my viewers and the content I'm showcasing. Especially highlighted in Lab 4, I want to emphasize the importance of having readable, digestible content on a computer screen – for all types of groups to enjoy. Although my website isn't extremely advanced yet, I wanted to create something both easy to read and straightforward to customize. Implementing a dark to light mode was a great challenge I took on along the way, and is available to use on all pages of my portfolio.

Data Analytics

Working with resources like Tableau and Mapbox in labs 4 and 6 deepened my understanding of using real-time data to create visually appealing results. I really enjoyed playing around with various AI platforms within VS Code itself, learning from AI Vibe Coding services, and experimenting with how AI can aid your coding capabilities and strengthen the areas in which you might lack skill. Although AI can sometimes be a harmful tool in higher education, this course has taught me that AI for coding is actually a great resource when you have a very specific inquiry. AI can aid you in the right steps to getting "unstuck" with messy or incorrect code, and can help you learn the foundations of learning strategies personalized and tailored completely to you.

Project Design and Planning

I wanted my portfolio to be easy to follow, with every section smoothly guiding you to the next. I took inspiration from various student portfolios I've seen online and of my classmates, and found it fun to implement my own twist on a bright color palette paired with a simple, yet bold font choice.

Collaboration

In this portfolio, I've explored collaboration with various development tools, including Mapbox, Tableau, Claude Sonnet 4.5, and Google Sheets (for CSV files), to create a website highlighting my projects as a student while learning more about these individual software platforms. I really enjoyed troubleshooting errors and understanding how each piece of software can integrate into VS Code. Using Claude Sonnet 4.5 towards the end of my portfolio was extremely helpful, as the software occasionally suggested downloading specific add-ons to make ideas and visuals run more smoothly. I especially found this helpful when I wanted to add PDF documents of my resume and previous work, as Claude Sonnet 4.5 recommended I download vscode-pdf to make these documents work smoothly with the rest of my website design.

Over the course of the semester, I've produced a portfolio highlighting my hard work in DCDA and beyond the classroom through other relevant coursework and real-world experience. After receiving each lab's feedback, I would make sure to fix any errors in previous labs for the next assignment, and triple-check my work before submitting the following lab. An area where I believe I grew significantly was in my visualization integration and understanding of user experience. I'm really fascinated by design and creating material that is easily accessible for all.

I made several updates to improve both the look and functionality of my portfolio website. I updated my homepage with a newer headshot and fixed a few minor grammatical errors throughout the site. I also restructured the welcome page so my headshot now sits side by side with my about me section, rather than appearing underneath it, which makes the page feel more balanced and easier to read.

Using vibe coding with Claude Sonnet 4.5 and VS Code chat, I worked on integrating my previous projects into a carousel, where visitors can click each image to open a full project page in a separate tab in my portfolio. This process took several attempts because I had to be very specific with my prompts and troubleshoot response errors before the code worked correctly. Once I understood how the code was functioning, I was able to tweak it and add a "Work Samples" section across all pages so employers can easily find my projects right away. VS Code chat also recommended installing a PDF extension and suggested simplifying my file names, such as renaming them to formats like "7eleven-presentation.pdf," which helped the files display correctly. It also helped me structure thumbnail images like "7eleven-thumbnail.jpg," which made the carousel function properly.

I also used AI to clean up the navigation menu and improve the user experience of my portfolio. I created a dropdown menu that lets visitors easily access all of my labs, and after troubleshooting issues where the menu would disappear when hovering, I worked with AI to fix the behavior. I also added "Next Lab" navigation buttons at the bottom of each lab page to help viewers move through the assignments more easily. Each button links to the next lab and includes a small hover animation that slides it slightly to the right when a user interacts with it.

Finally, I worked with Claude to improve the overall flow of the lab pages. I implemented dropdown sections within each lab to make the information easier to read and less overwhelming. At first, the transition felt abrupt when a section was closed, so I updated the CSS to create smoother animations. I added a minimum height to the main container to prevent the footer from jumping when sections expand or collapse, and applied consistent transition timing across containers to make the experience feel more polished and calm for the user.
