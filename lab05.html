Lab 5: Vibe Coding

For this lab, I experimented with AI as a coding collaborator to see when it helps and when it becomes problematic. I used AI to generate and modify code for different tasks while making sure I could still read, explain, and understand what the code was doing. This lab helped me think more critically about how to responsibly use AI in development without losing control of the work.

Vibe Coding Reflection & Analysis

Using the chatbox feature in Visual Studio Code, I used Claude Sonnet 4.5 to Vibe Code a dark mode toggle button, as well as the basic blueprint for an image carousel that I plan to update with real-world examples as a highlight of what I’m capable of producing as the semester goes on. With internship experience in graphic design, digital marketing, campaign execution, social media management, and visual branding, I want to find innovative ways to showcase my creations and projects in my portfolio to potential employers and website visitors. I believe that any type of “visual carousel” is an innovative and interactive way to showcase hard work, and using vibe coding to describe what I was hoping to get out of it was a great success. My site now features a toggle button at the top right corner that can actively switch back and forth from light mode (via the sun emoji), or dark mode (a darker web interface via the moon emoji) to appeal to users’ differing preferences when viewing a website on their computers or on a mobile device. I used AI to learn and understand how this toggle integration created a smooth visual transition from dark to light mode using the CSS transition coding feature in HTML. Through learning how to produce this code;

html {
  transition: background-color 0.3s ease, color 0.3s ease;
}

* {
  transition: background-color 0.3s ease, color 0.3s ease, border-color 0.3s ease;
}

I applied it, and I can see a gradual transition from light to dark web interfaces, and vice versa, which creates a nice flow and an upscale look for my website. Additionally, throughout my back-and-forth with my chatbox, I created a sample-size carousel on my work homepage to showcase the work I want to showcase. I look forward to integrating these design changes into my portfolio more as the semester goes on and to creating even more intricate ones.

I’ve had a lot of success with using AI in Vibe Coding, specifically Claude Sonnet 4.5. In class, we completed an exercise where we Vibe Coded a mini game using similar prompts. Throughout my experience using these platforms, I’ve found AI really helpful when I'm feeling stuck or confused, or when a string of code isn’t displaying the way I planned. Between our interactive class discussion of creating mini games and the feedback I’ve gotten from different AI platforms, I’ve learned the importance of specific wording, providing it feedback when you (as a user) don’t like what it generated for you, and that it is always extra important to check its work. Since for this exercise I just used AI to walk me through and lay the “groundwork” for my HTML and CSS styling pages, I wanted to learn as much as I could through keeping my prompts straightforward and the coding clean. When I learned how to integrate an image carousel into my homepage, Claude Sonnet 4.5 created a CAROUSEL_GUIDE.md section with blank instructions for installing a carousel in my code, providing the basics to highlight well-thought-out portfolio pieces interactively.

In terms of using AI down the line in building my portfolio, I plan to use it as a tool to walk me through situations when I seem stuck or confused. Using AI as a tool rather than a cheat code makes me a stronger coder and a stronger individual, with strengths in the DCDA categories. Learning from my mistakes when asking for feedback from AI can teach my peers and me to code ethically and intentionally.
